# 5. Things to carry

[Tutorial](index.md) · Previous: [Understanding words](04-understanding-words.md) · Next: [Darkness and danger](06-darkness-and-danger.md)

The castle holds four things: a lamp, the amulet, some bread, and a coin. Each has a name and a place.

## Parallel arrays

```basic
10100 REM OBJECTS: NAME, WHERE IT STARTS (0 MEANS CARRIED)
10110 DATA 4,LAMP,4,AMULET,6,BREAD,7,COIN,3
```

```basic
9040 READ NO:DIM OB$(NO),OL(NO)
9050 FOR I=1 TO NO:READ OB$(I),OL(I):NEXT
```

`OB$(I)` is object `I`'s name, and `OL(I)` its location: a room number, or 0 when the player carries it. Two arrays that use the same subscript for the same thing are called **parallel arrays**; BASIC V2 has no records or structures, so this is how programs kept several facts about each thing.

To move an object, the program changes one number: taking the lamp sets `OL(1)=0`, and dropping it in room 2 sets `OL(1)=2`.

## Seeing objects

The room description lists what is there:

```basic
1060 FOR I=1 TO NO
1070 IF OL(I)=R THEN PRINT "THERE IS A ";OB$(I);" HERE."
1080 NEXT
```

## Finding an object by name

`TAKE` and `DROP` both need to find the object the player named:

```basic
3910 O=0:FOR I=1 TO NO
3920 IF LEFT$(NN$,3)=LEFT$(OB$(I),3) THEN O=I
3930 NEXT:RETURN
```

Like verbs, objects are matched on their first three letters. A subroutine that both `TAKE` and `DROP` call keeps the search in one place.

## TAKE and DROP

```basic
3210 IF NN$="" THEN PRINT "TAKE WHAT?":RETURN
3220 GOSUB 3900:IF O=0 THEN PRINT "I DON'T KNOW WHAT THAT IS.":RETURN
3230 IF OL(O)=0 THEN PRINT "YOU ALREADY HAVE IT.":RETURN
3250 OL(O)=0:PRINT "TAKEN.":RETURN
```

The same **check, then return** pattern from chapter 3: each line rules out one problem, and only a command that passes every check does anything.

## The inventory

```basic
3410 N=0:PRINT "YOU ARE CARRYING:"
3420 FOR I=1 TO NO
3430 IF OL(I)=0 THEN PRINT TAB(2);OB$(I):N=N+1
3440 NEXT
3450 IF N=0 THEN PRINT TAB(2);"NOTHING"
```

`N` counts what is carried, so that an empty inventory says so. `TAB(2)` indents the list.
